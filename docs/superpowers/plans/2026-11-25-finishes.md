# Finishes (Step 15) Implementation Plan

**Working agreement (mandatory):** keep this plan in sync with reality. Check a step only when it is finished and its gate is green. Append every divergence to the Drift Log. When a drift changes a decision of the spec, add a new spec doc rather than rewriting the spec.

**Status:** built and committed by the AI in a throwaway clone, while the author slept, as four stacked branches. The design choices were the AI's (spec F1 to F22). The branches were first stacked on `feat/library-timeline`, then rebased on `feat/send-flow` (step 17) before the report. What is left: the controller's Bruno run, the Chrome checks and the author's UX walkthrough (Final verification).

**Goal:** the app feels finished on a phone: installable, never blank while loading, honest when offline, with a viewer that closes with a swipe, zooms with two fingers, tells a photo's infos and shares it outward.

**Tech Stack:** React 19, Radix (shadcn `sheet`, `dropdown-menu`), embla-carousel 8.6, lucide-react, Tailwind 4; Express 5, Prisma 6.19 (MongoDB), Cloudinary; Vitest, Biome 2, Bruno CLI. Pointer events, the Web Share API, `srcset`, a web manifest. No new dependency.

## Global Constraints

- **No new dependency.** Explicitly no `vaul`, no `vite-plugin-pwa`, no service worker.
- **Prisma stays on v6.** The three new `Photo` fields are optional: no `db:push` is needed (MongoDB has no columns, and no index changes).
- **Every gesture has a button or a key**: drag down → ✕ and Escape; pinch → `+`/`-` and double tap/click; the drawer drag → ✕, Escape, a tap outside.
- **`prefers-reduced-motion`**: every spring-back and fade goes through `motion-safe:` or `motion-reduce:transition-none`.
- **Gate per commit:** `pnpm exec biome check client server/src server/prisma server/bruno docs` and `pnpm typecheck`; at the tip `pnpm build` and `pnpm test`.
- **Stay away** from the tab bar, the add panel, the share flow and `LibraryHeader` (step 17).

The icons were rendered once by a throwaway script, not committed, run from `server/` (where `sharp` is installed) on two hand-written SVGs (`favicon.svg`, committed, and a full-bleed `maskable.svg`):

```js
import { readFileSync } from 'node:fs'
import sharp from 'sharp'
const [dir, out] = process.argv.slice(2)
const any = readFileSync(`${dir}/favicon.svg`)
const full = readFileSync(`${dir}/maskable.svg`)
await sharp(any, { density: 300 }).resize(192, 192).png().toFile(`${out}/icon-192.png`)
await sharp(any, { density: 300 }).resize(512, 512).png().toFile(`${out}/icon-512.png`)
await sharp(full, { density: 300 }).resize(512, 512).png().toFile(`${out}/icon-maskable-512.png`)
await sharp(full, { density: 300 }).resize(180, 180).png().toFile(`${out}/apple-touch-icon.png`)
```

3. **A heredoc broke on a quote** while writing `photoGestures.ts` (the word `'idle'` in a comment closed the shell quote); the file was then written with the editor tool. No effect on the code.
4. **The brief's « raccourcis clavier »** (keyboard shortcuts on a phone keyboard) became F7, the phone keyboard hints; the viewer's real shortcuts are F13.
5. **The invitation link share** (F22) was included although the controller only asked for the photo share: the brief named it, and it is three lines.
