# shadcn/ui setup

- Date: 2026-11-23
- Changes: the client styling, plain CSS in `client/src/index.css` until now
- AI usage: requested by the author; Claude Code ran `shadcn init` and adjusted the generated setup to the repo rules.

## Decisions

| Topic           | Choice                                                                       | Why                                                                                                                            |
| --------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Styling engine  | Tailwind CSS v4 through `@tailwindcss/vite`                                  | shadcn/ui requires Tailwind. v4 needs no `tailwind.config`: the theme lives in `index.css`.                                    |
| Init            | `shadcn init -t vite -b radix -p nova`                                       | Radix primitives are the most documented base; `nova` is the default preset.                                                   |
| Import alias    | `@/*` → `src/*` in `tsconfig.json`, `tsconfig.app.json` and `vite.config.ts` | The shadcn CLI reads the alias from the root `tsconfig.json`. No `baseUrl`: TypeScript 7 resolves `paths` without it.          |
| Build-time deps | `tailwindcss`, `@tailwindcss/vite` in `devDependencies`                      | Same as `vite`: only the build uses them.                                                                                      |
| Biome           | `css.parser.tailwindDirectives: true`                                        | Biome otherwise rejects `@apply`, `@theme` and `@custom-variant` as parse errors.                                              |
| Root styles     | Removed `font-family` and `color-scheme` from `:root`                        | Unlayered, they overrode the theme font (`@layer base`). `color-scheme: light dark` styled native inputs dark on a light page. |

## Generated code

`src/components/ui/` and `src/lib/utils.ts` come from the shadcn CLI. They are vendored as generated, only formatted by Biome: the project code rules (explicit return types, naming) apply to our code, not to these files, so that `shadcn add` updates stay diffable.

## Not done yet

- **Dark mode**: the theme defines a `.dark` class, nothing toggles it. The app followed the OS before through `color-scheme`; it is light-only for now.
- **Page migration**: pages still use the classes from `index.css` (`.upload`, `.frame-*`). Only the upload submit button uses `<Button>`, as a smoke test. Tailwind's preflight resets default margins and heading sizes, so the pages look plainer until migrated.
